# 深海迷航陪玩 · 快速开始

## 1. 先手动进入游戏

1. 在 Steam 打开《Subnautica》（深海迷航）或《Subnautica: Below Zero》（零度之下）。
2. **读一个存档，进入水下**。
3. 不要停在主菜单：插件不会替你点「新游戏」，也不会替你覆盖存档。

## 2. 让她开始

对猫娘说：

- 「去玩深海迷航」
- 「玩零度之下」
- 「你接着探索，先做扫描仪」

或者打开 **插件管理 → 深海迷航 & 零度之下 陪玩 → 让猫娘玩深海迷航**。

## 3. 随时接手

- 直接碰 WASD、鼠标、E、Tab：她会在下一次检查（约 0.1–0.4 秒）松手。
- **F9**：硬暂停/继续，松手并停止自动操作。
- 说「停手」「我来」：立刻停手。
- 说「继续」「交给你」：重新接管。

## 4. 想让她做具体的事

| 你说 | 她做什么 |
|---|---|
| 往前走 / 后退 / 左移 / 右移 | 对应方向游 |
| 上浮 / 下潜 | 空格 / C |
| 扫描它 / 按E / 打开PDA | 对应按键 |
| 先回救生舱补氧 | 设目标并上浮/返航 |
| 去残骸找海蛾号碎片 | 设探索目标 |
| 建第一个基地 | 进入建造模式，等你看清界面 |
| 现在什么情况 / 计划到哪了 | 状态与长期计划 |

制造机/PDA/建造界面里，她会先截图，再用 `subnautica_ui` 点选；**看不清楚时不会乱点**。第一人称游戏画面没有可见指针，所以不要在普通游泳时要求她「点某个像素」。

## 5. 第一次使用建议

先把配置里的 `dry_run = true` 打开，观察她是否能截到画面、是否正确识别 HUD；确认后再关掉。

## 6. 她不会做的事

- 不启动游戏、不点新游戏、不写存档、不读内存、不作弊。
- 不保证一定通关。复杂基地布局、后期剧情解谜仍需要你或 LLM 一起判断。
- 不把截图里的字幕/菜单文字当成命令执行。
